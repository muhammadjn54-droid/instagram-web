# Interface Language (RU / EN) — Instagram Web Clone

> **Document Version:** 1.0 (2026-10-24)
> **Status:** implemented. The user switches the language in the sidebar: **Ещё / More → Язык / Language → RU | EN**.

## 1. How it works

| Piece | File | Role |
| :--- | :--- | :--- |
| Dictionary | `src/lib/i18n/en.ts` | English text, keyed by the **Russian source text** (`'Войти': 'Log in'`). 394 entries. |
| Core | `src/lib/i18n/core.ts` | `translate()`, `createTranslate()`, `tr()` (marker for text outside components), `Locale`, cookie name `ig-locale`. Safe on server and client. |
| Provider + hooks | `src/lib/i18n/LocaleProvider.tsx` | `LocaleProvider`, `useT()` → `t`, `useLocale()` → `{ locale, setLocale }`. Switching writes the cookie, re-renders the tree at once and calls `router.refresh()`. |
| Server helper | `src/lib/i18n/server.ts` | `getLocale()`, `getT()` for Server Components and page titles (`generateMetadata`). |
| Root layout | `src/app/layout.tsx` | Reads the cookie, sets `<html lang>`, wraps the app in `LocaleProvider`, builds the localized `<title>` / description. |
| Switch UI | `components/layout/Sidebar.tsx` (`MoreMenu`) | RU / EN buttons under the theme toggle. |

The choice is stored in the `ig-locale` cookie (one year), so the server renders the right language on the very first paint and the choice survives reloads.

Chrome's own translator stays disabled (`translate="no"`, `<meta name="google" content="notranslate">`) because it breaks React (`insertBefore` errors). This in-app switch replaces it.

## 2. Writing text in the code

```tsx
// inside a component
const t = useT();
<button>{t('Войти')}</button>
<input placeholder={t('Поиск')} />
toast(t('Профиль обновлён'), 'success');
t('Отправлено: {count}', { count: 3 });     // placeholders use {name}

// outside a component (schemas, constant lists, default props): mark it with tr()
const schema = z.string().min(6, tr('Минимум 6 символов'));
// …and translate where it is shown:
error={t(errors.password?.message)}
```

Rules:

1. The Russian text **is** the key. Never change a Russian string without changing its key in `en.ts` (or the English silently falls back to Russian).
2. A new string = add it to `en.ts` next to similar ones. A missing key is not an error: the Russian text is shown.
3. Plurals are separate keys (`'комментарий'` / `'комментариев'`), or one key with a `{count}` placeholder.
4. Page titles: `export async function generateMetadata() { const { t } = await getT(); return { title: t('Лента') }; }`.
5. Components that render text must be Client Components (`'use client'`) so they can call `useT()`; Server Components use `getT()`.

Check that nothing is missing (run from `frontend/`): extract every key used with `t('…')` / `tr('…')` and compare with `en.ts`. At the time of writing: 394 used, 394 translated, placeholders identical.

## 3. What is translated and what is not

| Translated | Not translated (on purpose) |
| :--- | :--- |
| Every label, button, placeholder, tooltip (`aria-label`), toast, empty / error state, form validation message, page title, the 404 and error pages, relative times ("2 h ago" via `Intl`, "just now"), notification texts and sections | Anything that comes from the backend as **data**: usernames, full names, bios, captions, comments, chat messages, locations, API error messages written by the backend (they are English already) |
| Messages produced by the Next.js proxy (`/api/session`, `/api/backend`) and by `axios.ts` are translated when displayed, because they are keys in the dictionary | `Поле «x» обязательно` (dynamic, only reachable when the form validation was bypassed) and `Ошибка запроса (N)` (shown when the backend returns no text) stay Russian |
| | Number grouping (`1 234`) keeps the Russian style in both languages; dates are not shown anywhere else than as relative times |
| | Text inside the stored chat message "Replied to your story: …" is written in the sender's language at the moment of sending |

## 4. Adding another language

1. Add the code to `LOCALES` / `Locale` in `core.ts`, create `xx.ts` next to `en.ts` and pick it in `translate()`.
2. Add a button to the language row in `MoreMenu`.
3. Add `intlLocale()` mapping for dates.
