# 📋 План задач для Фронтенд-разработчика (Frontend Roadmap)

> **STATUS NOTE (2026-10-23):** steps 1–10 below are **implemented** (functionally). Differences: routes are `/messages`, `/profile/[userId]`, `/post/[postId]`; pagination replaces infinite scroll; modals for create-post / post / search are pages for now; Reels is a grid; JWT lives in an httpOnly cookie behind the `/api/backend` proxy instead of `src/lib/api.ts` + `localStorage`. What is still open: see `tz.md` §5–§6. The UI skin and the interaction extras (double-tap like, infinite scroll, drawers, reels player) are scheduled for the UI phase.


> **Привет, коллега!** 👋

### Шаг 1: Настройка API-клиента и типов
- [ ] Создать файл `src/lib/api.ts` (готовый код есть в [`FRONTEND_GUIDE.md`](./FRONTEND_GUIDE.md)).
- [ ] Создать файл `src/types/index.ts` с интерфейсами `User`, `Profile`, `Post`, `Comment`, `Story`, `Chat`, `Message`.
- [ ] Настроить хранение токена (`accessToken` в `localStorage` или `Cookies`).
- [ ] Проверить подключение: сделать тестовый запрос `GET http://localhost:3000/posts` в консоли браузера.

---

### Шаг 2: Страницы Авторизации (Auth)
- [ ] **Экран Входа (`/login`):**
  - Поля: Имя пользователя / Email, Пароль.
  - Кнопка "Войти" -> запрос `POST /account/login`.
  - При успехе: сохраняем `accessToken` и перенаправляем на `/` (Главная).
  - При ошибке: выводим понятное сообщение пользователю.
- [ ] **Экран Регистрации (`/register`):**
  - Поля: Имя пользователя, Полное имя, Email, Пароль, Подтверждение пароля.
  - Запрос `POST /account/register`.
  - Валидация: пароль минимум 6 символов, пароли совпадают.
- [ ] **Экран Восстановления пароля (`/forgot-password`):**
  - Поле: Email -> запрос `POST /account/forgot-password`.
  - Экран ввода нового пароля с токеном -> `POST /account/reset-password`.

- [ ] **Боковая панель (Sidebar для десктопа):**

- [ ] **Защита маршрутов (Route Guard):**
  - Если токена нет -> перенаправлять на `/login`.

### Шаг 4: Главная страница — Истории и Лента постов (`/`)
- [ ] **Блок историй (Stories Bar) сверху:**
  - Запрос: `GET /stories` (активные истории подписок) + `GET /stories/me` (моя история).
  - Аватарка в градиентной рамке (фиолетово-оранжевой).
  - Клик по истории открывает полноэкранный просмотрщик (Story Viewer):
    - Таймер прогресса (5 секунд на историю).
    - Переключение вперед/назад кликом по краям.
    - Кнопка лайка истории (`POST /stories/:id/like`).
    - Засчитывать просмотр при открытии (`POST /stories/:id/views`).
- [ ] **Лента постов (Feed):**
  - Запрос: `GET /posts/feed?pageNumber=1&pageSize=10`.
  - Карточка поста:
    - Шапка: аватарка автора, имя, локация, кнопка меню (три точки).
    - Карусель картинок (если картинок несколько — точки-индикаторы и стрелки влево/вправо).
    - Кнопки действий: Сердечко (Лайк), Сообщение (Комментировать), Самолётик (Поделиться), Флажок (В закладки).
    - Счётчик лайков: "Нравится: 142".
    - Текст описания поста + ссылка "ещё...", если текст длинный.
    - Ссылка "Посмотреть все комментарии (X)".
    - Время публикации ("2 часа назад").
  - Интерактивность:
    - Клик по сердечку -> `POST /posts/:id/like` или `DELETE /posts/:id/like` (с мгновенным обновлением UI).
    - Двойной тап по картинке -> анимация большого сердца по центру и лайк.
    - Клик по флажку -> `POST /posts/:id/favorite` или `DELETE /posts/:id/favorite`.
  - Бесконечная прокрутка (Infinite Scroll) при скролле вниз.

### Шаг 5: Модальное окно поста и Комментарии
- [ ] **Модалка просмотра поста:**
  - Запрос: `GET /posts/:id` и `GET /posts/:id/comments`.
  - Слева — большая фотография или карусель.
  - Справа — шапка автора, скроллируемый список комментариев, форма ввода комментария.
- [ ] **Добавление комментария:**
  - Поле ввода: "Добавьте комментарий..." + кнопка "Опубликовать".
  - Запрос: `POST /posts/:id/comments` с телом `{ comment: "..." }`.
  - После отправки комментарий мгновенно появляется в списке.
- [ ] **Удаление комментария:**
  - Кнопка корзины (если комментарий мой или я автор поста) -> `DELETE /comments/:id`.

---

### Шаг 6: Модальное окно создания публикации
- [ ] **Окно "Создание публикации":**
  - Шаг 1: Drag & drop область для выбора файлов (от 1 до 10 картинок JPG/PNG/WEBP).
  - Шаг 2: Предпросмотр выбранных картинок, возможность менять порядок или удалять.
  - Шаг 3: Поле для текста публикации (caption).
  - Шаг 4: Выбор локации (поиск через `GET /locations?search=...`).
  - Чекбокс: "Опубликовать как Reel (видео/рилс)".
  - Кнопка "Поделиться" -> отправка `FormData` на `POST /posts`.
  - После успешной публикации: закрытие окна и обновление ленты.

---

### Шаг 7: Страница Профиля (`/profile` или `/:username`)
- [ ] **Шапка профиля:**
  - Запрос: `GET /profiles/me` (для своего) или `GET /profiles/:userId` (для чужого).
  - Аватарка (для своего профиля — клик открывает выбор нового фото -> `PUT /profiles/me/avatar`).
  - Статистика: постов, подписчиков, подписок.
  - Имя, био (описание), ссылка на сайт.
  - Кнопки:
    - Свой профиль: "Редактировать профиль" (модалка с `PATCH /profiles/me`), "Настройки".
    - Чужой профиль: кнопка "Подписаться" (`POST /users/:userId/follow`) или "Отписаться" (`DELETE /users/:userId/follow`), кнопка "Написать сообщение".
- [ ] **Вкладки под шапкой:**
  - 1. **Публикации (Сетка 3x3):** картинки постов с hover-эффектом (показывает иконки лайков и комментов).
  - 2. **Сохранённое (Закладки):** `GET /profiles/me/favorites`.
  - 3. **Рилсы:** посты с флагом `isReel: true`.
- [ ] **Модалка со списком подписчиков и подписок:**
  - Запрос: `GET /users/:userId/followers` и `GET /users/:userId/following`.

---

### Шаг 8: Личные сообщения (Директ / `/direct`)
- [ ] **Левая колонка — Список диалогов:**
  - Запрос: `GET /chats`.
  - Карточка диалога: аватарка собеседника, имя, последнее сообщение, индикатор непрочитанного.
  - Кнопка "Написать новое сообщение" (поиск юзера и `POST /chats`).
- [ ] **Правая колонка — Активный чат:**
  - Шапка: имя и аватарка собеседника, ссылка на его профиль.
  - История сообщений: `GET /chats/:chatId/messages`.
    - Сообщения текущего юзера справа (синие/серые), собеседника слева.
    - Поддержка прикрепленных картинок (`/uploads/...`).
  - Отметка о прочтении: `PATCH /chats/:chatId/read` при открытии.
  - Поле ввода:
    - Текстовый инпут + кнопка прикрепления файла (иконка скрепки/фото).
    - Отправка по Enter или клику по стрелочке -> `POST /chats/:chatId/messages`.

---

### Шаг 9: Поиск и Раздел "Интересное" (Explore)
- [ ] **Панель поиска пользователей:**
  - Инпут с дебаунсом (300 мс).
  - Запрос: `GET /users?search=...`.
  - Недавние поисковые запросы: `GET /search-history`, добавление в историю `POST /search-history`, удаление `DELETE /search-history/:id`.
- [ ] **Экран "Интересное" (`/explore`):**
  - Запрос: `GET /posts?pageNumber=1&pageSize=18`.
  - Асимметричная Instagram-сетка (квадраты + большие плитки).

- [ ] Полноэкранный вертикальный скролл ленты рилсов.
